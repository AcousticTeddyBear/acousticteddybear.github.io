Paste a GitHub token that can read the docs. It stays in this browser.

How to get a token

  1. Open https://github.com/settings/personal-access-tokens/new.
  2. Set the resource owner to AcousticTeddyBear, and choose only the splitsteps-docs repository.
  3. Under Repository permissions, set Contents to Read-only.
  4. Generate the token and paste it here.
